# U2-ejercicio18

### Ejercicio: El Sistema de Facturación y Emisión de Tickets

**Objetivo:** Modelar la comunicación entre objetos en Java mediante el envío de documentos complejos como parámetros, permitiendo que una caja registradora envíe una factura completa a una impresora fiscal para su procesamiento e impresión.

Desarrollo de un sistema de facturación utilizando las clases `ItemFactura`, `Factura`, `ImpresoraFiscal`, `CajaRegistradora` y `Main`, aplicando encapsulamiento, composición, manejo de listas y comunicación entre objetos.
